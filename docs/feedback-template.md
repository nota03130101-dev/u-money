# U Money 小范围内测反馈

请只填写下面的问题。不要填写密码、真实收入、真实账单、邮箱访问密码、API 信息、访问令牌或 CSV 文件内容。

## 1. 哪一步无法完成？

填写步骤编号、看到的现象，以及你原本以为会发生什么。

## 2. AI 哪些内容识别错误？

填写虚构测试句子，以及日期、类型、金额、类别或备注中哪一项不对。

## 3. 哪个提示看不懂？

填写提示原文，以及你觉得不清楚的地方。

## 4. 你是否知道 AI 结果需要确认后才会保存？

选择：知道 / 不知道 / 不确定。

## 5. 手机显示是否正常？

填写：正常 / 不正常。

如不正常，只说明文字、按钮、输入框或页面滚动哪里有问题；不要提供真实账单截图。

## 6. 你觉得最有用的功能是什么？

填写一个功能和原因。

## 7. 你觉得最不需要的功能是什么？

填写一个功能和原因。
